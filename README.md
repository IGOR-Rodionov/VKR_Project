# VKR_Project

Это старая версия проекта, которая по ошибке была отправлена на рецензирование. Она содержит только графического интерфейса, а вместо реализованных инструментов для хужожественной обработки звука используется встроенные функции и классы `juce`.  Полная версия проекта находится в ветке `main`.
